## Non-capability evidence

- PR #293 (merged as `c5df14a`) makes the portable EDL package retain saved transitions, timed title/caption kind and position, and a project-owned audio mix; packaged sources are copied and hash-verified. Its structural ZIP evidence is superseded for prepared-engine delivery rendering by PR #319, which closes that path at partial L2.

- PR #320 adds the shared [`comfyuipod.agent-run` v1 contract](../agent-harness-contract.md) and durable secret-free run evidence. Studio enforces its tool allowlist at dispatch, bounds context, shares call budgets with child runs, and checks iteration/wall-time/cancellation at safe boundaries. OpenCode and Command Code launchers write the same run envelope and enforce process wall time. Their private tool dispatch, internal context counters, and runtime-created children remain advisory without runtime hooks; agents bypassing the adapter are untracked. The 115-test Studio agent suite and a harmless external-launcher fixture pass. This establishes an adapter contract, not enforcement inside every third-party runtime.

- Merged PR #322 extends the harness into runtime hooks for OpenCode and Kilo, and a required launcher/mod path for Command Code. The hooks create run records, bound model/tool calls, apply tool policies, checkpoint context, link child sessions to parents, intersect child permissions with the parent, and close interrupted processes. Validation includes a live Kilo CLI primary run and synthetic child/exit hook tests; the installed Kilo CLI did not expose its task tool, so Kilo child delegation was not live-verified. Command Code sessions are enforceable only when launched through `scripts/cmd-agent`. PR checks and main image promotion passed; the promoted main image is recorded in this snapshot. This does not certify arbitrary unregistered agent platforms.
