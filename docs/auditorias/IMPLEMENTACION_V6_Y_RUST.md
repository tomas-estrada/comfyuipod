## 5. Desviaciones Documentadas y su Justificación

1. **Elección de `chrono` dentro de la disyuntiva `"time o chrono (uno solo)"` de `§4.2`**:
   - `time <= 0.3.46` dispara el advisory `RUSTSEC-2026-0009` en `cargo-deny`, mientras que `time >= 0.3.47` exige `rustc 1.88.0` (superior al MSRV `1.86.0`). Con `chrono = { version = "0.4", default-features = false, features = ["std"] }`, compila en `rustc 1.86.0`, pasa `cargo deny check` con `0` advisories y mantiene `cargo tree | wc -l` en **32 líneas** (`<= 40`).
2. **Enlazado dinámico `glibc` (`2.36` → `2.39`) en lugar de `musl` (`R-09`)**:
   - `rust:1.86.0-slim-bookworm` incluye únicamente la stdlib `x86_64-unknown-linux-gnu` (contra `glibc 2.36` de Debian 12) y no incluye `musl-tools`. Compilar para `x86_64-unknown-linux-gnu` evita descargas de red adicionales (`apt` / `rustup target add`) durante `docker build` y es 100% compatible hacia adelante con `glibc 2.39` de `nvidia/cuda:12.8.0-runtime-ubuntu24.04`. El paso 13 del smoke test verifica explícitamente la lista blanca de librerías dinámicas en `ldd /usr/local/bin/comfyctl`.
3. **Código de salida `20` en fallo `FATAL` de `strict-check` (`R-06` / §6 de V7)**:
   - Se conserva el código de salida `20` (consistente entre `comfyctl`, el smoke test de CI, `tools/mac/comfy` y la documentación) conforme a la recomendación del auditor en `AUDITORIA_AGENTE_V7.md` (`R-06` y `§6`).
