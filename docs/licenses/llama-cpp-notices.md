# Unicode notice for llama.cpp generated tables

`src/unicode-data.cpp` in the pinned llama.cpp revision contains generated
canonical-normalization tables identified upstream as Unicode 16.0.0. The
upstream generator uses Python `unicodedata` for the canonical combining-class,
decomposition, and composition tables. The Unicode Character Database 16.0.0
ReadMe identifies the data as © 2024 Unicode, Inc. This file accompanies the
generated tables in the packaged `llama-server` image.

Sources:

- Unicode Character Database 16.0.0 ReadMe: <https://www.unicode.org/Public/16.0.0/ReadMe.txt>
- Pinned llama.cpp table generator: <https://github.com/ggml-org/llama.cpp/blob/cd959bae99ff4bed22bef2604f45241c09bbb8c8/scripts/gen-unicode-data.py>
