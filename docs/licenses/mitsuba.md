# Mitsuba 3.9.1 and Dr.Jit 1.5.0 notices

The Comfy Studio image includes the Mitsuba and Dr.Jit Linux wheels for its
bounded CPU inverse-rendering fixture. The wheels are pinned and hash-verified
by [`studio/locks/mitsuba-cp312-linux-amd64.lock`](../../studio/locks/mitsuba-cp312-linux-amd64.lock).
No model weights or user scenes are redistributed by this dependency.

reproduced below for binary redistribution, following the upstream license
files at [Mitsuba 3 v3.9.1](https://github.com/mitsuba-renderer/mitsuba3/blob/v3.9.1/LICENSE)
and [Dr.Jit v1.5.0](https://github.com/mitsuba-renderer/drjit/blob/v1.5.0/LICENSE).
