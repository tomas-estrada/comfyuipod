# Walkthrough del repositorio: ComfyUI + Comfy Studio para Vast.ai

Este documento detalla la función de cada archivo y conserva resultados de verificaciones de una revisión anterior. Los conteos y salidas de CI que siguen son snapshots históricos: usa `AGENTS.md` y la CI del commit actual para decidir qué está pasando hoy. La implementación de [`docs/propuestas/OBSERVABILIDAD_Y_PORTAL.md`](propuestas/OBSERVABILIDAD_Y_PORTAL.md), la migración a Rust de [`docs/propuestas/IMPLEMENTACION_RUST.md`](propuestas/IMPLEMENTACION_RUST.md) (`comfyctl`) y el hito M2 (**Comfy Studio**, `MODEL_PROFILE=studio`) y los hitos M3–M7 (percepción visual/facial, ASR y diarización, EDL, motores, orquestación, brief creativo, estudio de anuncios y montaje desde brief).
