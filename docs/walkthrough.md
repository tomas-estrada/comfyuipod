# Walkthrough del Repositorio: ComfyUI "Everything-Ready" para Vast.ai

Este documento detalla la función de cada archivo del repositorio y las verificaciones realizadas tras las rondas de auditoría V1–V9, la implementación de [`docs/propuestas/OBSERVABILIDAD_Y_PORTAL.md`](propuestas/OBSERVABILIDAD_Y_PORTAL.md), la migración a Rust de [`docs/propuestas/IMPLEMENTACION_RUST.md`](propuestas/IMPLEMENTACION_RUST.md) (`comfyctl`) y el hito M2 (**Comfy Studio**, `MODEL_PROFILE=studio`).
